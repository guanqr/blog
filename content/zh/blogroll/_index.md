## 申請方式

+ 首先將本站鏈接添加至你的網站，信息如下：

```
網站名稱：荷戟獨彷徨
網站地址：https://guanqr.com/
網站標誌：https://guanqr.com/images/logo.png
網站描述：愛光學，愛生活，愛創造
```

+ 將你的網站信息按照上述格式在 [issues](https://github.com/guanqr/blog/issues/5) 中留言，審核通過後將會添加至該頁面中。請勿在文章評論區進行友鏈申請。

## 溫馨提示

+ 本人工作較忙，審核通過的時間一般在一周內，請耐心等待。
+ 友鏈申請後，我會隱藏您的申請（marked as resolved）表示審核通過，您的友鏈會添加在本頁面中。
+ 本站為個人小站，友鏈僅僅是作為朋友標記及訪問使用，不作為商業推廣，因此只添加個人博客網站。
+ 我會依據個人喜好對友鏈進行排序。我希望您的網站能夠記錄一些個人的思考，不要有太多的廣告。
+ 我會定期造訪友鏈。如果您的網站訪問異常，或一年以上未更新內容，將會被視作廢棄網站，在下方公示一個月後撤除。如果您因網站變更或其他原因主動撤除友鏈，本人會立即撤除，不再公示。若更改網址，請及時聯繫我進行更新。
